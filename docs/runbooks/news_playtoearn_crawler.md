# PlayToEarn crawler runbook

## Симптомы

- Заголовок статьи или подзаголовки оказываются над соседним абзацем после перевода.
- Вместо lazy-loaded изображения статьи в теле виден placeholder или повтор обложки.

## Как устроен сбор

- Настройки источника `playtoearn.com` задаются в `lib/tasks/news.rake`.
- Для заголовка используется `h1`; тело берётся из `article`. Встроенный `h1` удаляется из тела, поскольку заголовок сохраняется отдельно.
- Для текста абзацы и заголовки извлекаются из одного HTML-фрагмента и в порядке документа. Не превращайте весь фрагмент в одну строку: переводчик сопоставляет блоки текста с блоками HTML по порядку.
- Для изображений сначала проверяется `og:image` / `twitter:image`, затем изображения статьи. Lazy URL (`data-src`, `data-lazy-src`, `data-original`, `data-srcset`, `srcset`) нужно переносить в `src`, когда `src` — placeholder. Не удаляйте разные изображения статьи при дедупликации вариантов размеров.
- PlayToEarn может вставлять обложку в `.__NewsImage` после вводного абзаца; URL миниатюры и большой версии могут иметь разные числовые префиксы, но общий идентификатор `news_article_<hash>`. Такой image-only блок удаляется, если идентификатор совпадает с обложкой. Остальные изображения тела должны сохраняться.
- Не удаляйте пустые абзацы до выравнивания блоков: пустой `<p></p>` не соответствует элементу `body_text` и не должен потреблять перевод следующего заголовка или абзаца.
- API переписывает URL inline-картинок на `/body_image/<index>`. Endpoint должен разрешать индекс по тому же `body_html`, иначе удалённое при переводе изображение из исходника (например, обложка) сдвинет индексы и подменит inline-картинку.

## Проверка после изменений

Добавьте fixture в `test/services/news/section_crawler_test.rb`, где одновременно есть `og:image`, placeholder с lazy URL, встроенный `h1`, подзаголовок и отдельное изображение в теле. Проверьте `image_url`, порядок `body_text`, отсутствие встроенного заголовка в `body_html` и наличие изображения тела. Запустите:

```sh
bin/rails test test/services/news/section_crawler_test.rb
```

Для уже сохранённой статьи сравните `raw_payload.source_body_html` и `raw_payload.source_body_text` с переводом: если последовательности блоков не совпадают, сначала исправляйте извлечение, затем повторяйте перевод.
